# Analysis and Visualization in Python: MAKEUP Project  
### Analysis and Visualization in Python: MAKEUP Project

---

## Project Description
This project focuses on analyzing and visualizing data from the **makeup** catalog, obtained through an API. It covers all stages — from data collection to creating charts that help explore key catalog features and identify relationships.

---

## File Structure
- **JSON Files:**
  - `makeup_all_products.json`: JSON file containing all collected data.  

- **IPYNB Files:**
  1. `makeup_api_loading.ipynb`: Loading and saving data from the API.
  2. `makeup_research_dataset.ipynb`: Importing and conducting an initial exploration of the data.
  3. `makeup_data_preparation.ipynb`: Processing and preparing the data.
  4. `makeup_color_table.ipynb`: Creating a color table for visualizations.
  5. `makeup_project_visualization.ipynb`: Building charts for analytics.
  6. `makeup_project_visualization_unloading_png.ipynb`: Exporting charts as `.png` files.
  7. `makeup_presentation_pdf.ipynb`: Creating the presentation `Makeup_analysis_presentation.pdf`.
  8. `makeup_README_Pipeline.ipynb`: Creating and refining README.md and Pipeline.md.

- **CSV Files:**
  - `makeup_valid_prices.csv`: Products with valid prices.
  - `makeup_no_prices.csv`: Products with undefined prices.
  - `makeup_additional_info.csv`: Supplementary information.
  - `makeup_valid_prices_filled.csv`: Data with filled missing values.
  - `makeup_valid_prices_filled_columns.csv`: Data with additional columns for analysis.

- **Other Files:**
  - `color_table.html`: Color table in HTML format.
  - `color_table.png`: Color table as an image.
  - `Makeup_analysis_presentation.pdf`: Presentation in PDF format.
  - `Makeup_analysis_presentation.pptx`: Presentation in PPTX format.

---

## Technologies Used
- **Python:** Pandas, Matplotlib, Plotly
- **API:** Data collection via HTTP requests
- **Data Processing:** Normalization, filtering, analysis
- **Visualization:** Charts, heatmaps, histograms, and more
